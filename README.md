# Python Basics Exercises

A small beginner-friendly Python repository with two command-line exercises: checking whether an integer is prime and checking whether it is even or odd.

## Exercises

| File | What it does |
| --- | --- |
| `q1.py` | Checks whether an integer is prime |
| `q2.py` | Reports whether an integer is even or odd |
| `q1.txt`, `q2.txt` | Exercise prompts |
| `explanation1.txt`, `explanation2.txt` | Short explanations of the solutions |

## Requirements

- Python 3
- No third-party packages

## Run

From the repository directory, run either program:

```bash
python q1.py
python q2.py
```

Enter an integer when prompted. The program prints the result.
