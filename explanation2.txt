An even integer is divisible by 2 with no remainder. An odd integer leaves a remainder of 1 when divided by 2.

The program uses the remainder operator (%). If num % 2 equals 0, the function returns "even". Otherwise, it returns "odd".

For example, 6 % 2 equals 0, so 6 is even. Also, -3 % 2 is not 0, so -3 is odd.
